# AuraGen – Self-Healing Generative UI

AuraGen is an AI-powered adaptive UI system that detects user confusion from interaction patterns and dynamically generates personalized React interfaces using Generative AI.

## 🚀 Project Overview

Traditional user interfaces are static. AuraGen aims to make interfaces adaptive by detecting user interaction difficulties and modifying the UI in real time.

## ✨ Key Features

- User interaction tracking
- Cognitive Load Score
- AI-powered UI generation
- Dynamic React components
- Real-time UI adaptation
- Secure code validation
- Responsive and adaptive interface

## 🛠️ Technologies

- React.js
- Next.js
- Node.js
- LangChain
- Generative AI
- Tailwind CSS
- WebSockets
- Babel / AST
